# Contributing

This is currently a single-author portfolio project and is not accepting external
feature contributions.

Bug reports and reproducibility findings are welcome through GitHub Issues once
the repository is public. Include the affected release, operating system,
command, expected behaviour and a minimal synthetic reproduction.

Do not submit real company, customer, employee, banking or audit data. Do not
open a public issue for a suspected security vulnerability; follow
[SECURITY.md](SECURITY.md).

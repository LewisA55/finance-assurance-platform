# Roadmap and implementation record

This directory is an append-only implementation record, not the recommended
entry point for the product. Start with the repository [README](../../README.md)
and the [public release guide](../public-release/README.md).

## Current release path

- Milestones 0-3 establish the architecture, executable runtime and original
  governed public-product boundary.
- Milestone 4 records the governed analytical handoff and its successive
  assurance corrections. Artifact S v0.2-v0.12 files are historical review
  evidence; later regression tests still authenticate those authority steps.
- Milestone 5 builds the rich finance substrate, statutory model, executive
  marts and six React intelligence experiences.
- Milestone 6 is the `v0.1` public-release gate.

The numbered correction and reassessment files are deliberately retained. They
show how blocking provenance, mutation, reconciliation and consumer-authority
issues were found and closed; they are not separate current products or release
versions.

Future consumer-product milestones live under `consumer-products/`:

- `v0.2`: integrated Excel three-statement and DCF model;
- `v0.3`: Power BI semantic and reporting product; and
- `v1.0`: complete cross-product portfolio release.
